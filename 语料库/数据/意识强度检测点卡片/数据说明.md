# 意识强度检测点卡片数据说明

## 数据来源

- 来源：《意识强度检测点（1-9区）》（2018-2019年第三版），元吾氏催醒法研究。
- 说明：检测点 = 意识强度练习点。本文档数据为结构化整理版本，原文见 `语料库/意识强度系列/` 下对应 Markdown 文章。
- 版本：2018-2019年第三版。

## 文件清单

| 文件 | 内容 |
| --- | --- |
| `zones.json` | 总索引：9个区域及其名称 |
| `zone1.json` ~ `zone9.json` | 第1-9区的检测点层级数据 |

## 数据结构

### zones.json

顶层包含：

- `introduction`：前言，含标题、版本、作者、前言和结语。
- `zones`：区域索引，键为区域编号（`"1"` 至 `"9"`），值为 `{"id": ..., "name": ...}`。

### zoneN.json

每个区域文件包含两个顶层字段：

- `zone`：区域信息，含 `id`、`name`、`description`（区域说明）、`notes`（区域备注列表）。
- `hierarchy`：检测点层级列表。

### hierarchy 条目字段

| 字段 | 说明 |
| --- | --- |
| `id` | 检测点编号（如 `10001`、`31001`） |
| `level` | 层级，1-4 级，数字越小越靠顶层 |
| `name` | 检测点名称 |
| `description` | 检测点说明 |
| `note` | 备注（可为空） |
| `parent_id` | 父级检测点编号，顶层为 `null` |
| `is_card` | 是否为完整卡片条目（带指标和图片） |
| `metrics` | 指标数据，仅卡片条目有：`self`（含 `type`、`value.min/max`、`population`、`note`）和 `unit`（单位） |
| `display` | 展示信息，仅卡片条目有：`image`（图片资源引用）和 `text` |
| `zone_position` | 区域位置信息，仅卡片条目有 |

## 数据规模

- 检测点条目总数：302 个。
- 层级分布：第1级 13 个，第2级 40 个，第3级 90 个，第4级 159 个。
- 卡片条目（`is_card = true`）：243 个。
- 带指标（`metrics`）条目：264 个。
