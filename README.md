# 元吾氏古零语料库

## 简介

本项目整理元吾氏、古零相关公开资料，供阅读、检索和相关 AI 应用使用。

语料以 Markdown 文件为主，共 473 篇，按来源分为：

- `语料库/元吾氏/`：元吾氏署名的文章和答疑（91 篇）。
- `语料库/古零/`：古零署名的文章和答疑（360 篇）。
- `语料库/集体整理/`：作者未标明或由多人共同整理的资料，例如《反催眠百科》。
- `语料库/意识强度系列/`：意识强度相关的检测点、实操指南、抽样检测数据等文章（22 篇）。
- `语料库/数据/`：程序化使用的结构化数据，与正文分开存放，例如意识强度检测点卡片 JSON（字段说明见 `语料库/数据/意识强度检测点卡片/数据说明.md`）。

## 整理说明

- 语料主要来自微信公众号公开文章、群聊答疑记录，统一整理为 Markdown 格式。
- 已清理公众号扒取产生的噪声：OCR 图片转文字残块、微信链接追踪参数、导流页脚、失效图片引用、多余空行。
- 原文内容未改写；清理前后均经 Git 版本管理，可追溯。
- 每个文件一个一级标题，正文保留原始段落与对话结构。
