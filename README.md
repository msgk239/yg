# 元吾氏古零语料库

## 简介

本项目整理元吾氏、古零相关公开资料，供阅读、检索和相关 AI 应用使用。

语料以 Markdown 文件为主，按来源分为“元吾氏”“古零”“集体整理”和“意识强度系列”，每个来源下面再按内容类型分类。

## 获取语料库

项目地址：[msgk239/yg](https://github.com/msgk239/yg)

可以直接克隆仓库：

```bash
git clone https://github.com/msgk239/yg.git
```

也可以在项目页面点击 `Code`，然后选择 `Download ZIP` 下载。

## 内容说明

- `语料库/元吾氏/`：元吾氏署名的文章和答疑。
- `语料库/古零/`：古零署名的文章和答疑。
- `语料库/集体整理/`：作者未标明或由多人共同整理的资料，例如《反催眠百科》。
- `语料库/意识强度系列/`：意识强度相关的检测点、实操指南、抽样检测数据等文章。
- `语料库/数据/`：程序化使用的结构化数据，与正文分开存放，例如意识强度检测点卡片 JSON（字段说明见 `语料库/数据/意识强度检测点卡片/数据说明.md`）。

## 目录说明

- `README.md`：项目说明。
- `语料库/`：全部语料，以 Markdown 为主。
- `image/`：文档配图。
- 其他非 Markdown 数据文件（如 CSV）默认不进入本仓库，作为本地原始资料保留。
